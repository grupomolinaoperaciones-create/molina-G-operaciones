Conecta tu Google Sheet

Pega aquí el link público de tu Google Sheet para cargar los datos reales de tus gerencias. Los datos se actualizan cada vez que recargas o haces clic en "Actualizar".

⚠️ El Sheet debe ser público: en Google Sheets → Archivo → Compartir → Publicar en la web → selecciona la hoja → formato CSV → copia ese link.
Es diferente al link normal del Sheet. El link correcto termina en output=csv.

Mientras configuras el Sheet, la app muestra datos de ejemplo para que puedas explorar todas las funciones.
